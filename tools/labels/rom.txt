; ROM labels and directives for tools/disasm.py (CPU addresses $E000-$FFFF)
; AAAA name [; comment]               label
; code|data|words|rtswords AAAA-AAAA  force classification (rtswords: stored address = target-1)
; table AAAA-AAAA N [header]          data table, N bytes per row; references into it become name+offset
; text AAAA-AAAA                      ASCII string, emitted as .byte "..."
; split LO HI N [adj] [prefix]        lo/hi address tables of N entries (adj 1 = RTS trick)
; imm AAAA AAAA                       the immediates of these two instructions are #<target / #>target
; note AAAA ; text                    comment line printed before the line at AAAA
; bitskip AAAA                        BIT abs ($2C) skips a 2-byte instruction: AAAA = data, AAAA+1 = hidden code
; module AAAA name [; description]    source file src/prg/name.asm starts at AAAA (the first one at $E000)
; dbyt AAAA-AAAA                      16-bit numbers, big-endian: .dbyt $XXXX
; numwords AAAA-AAAA                  16-bit numbers (not addresses), little-endian: .word $XXXX
; Sources: TCRF (Galaxian NES/FDS page), GameHacking.org RAM codes, code analysis. (?) = guess, verify.

; ---- interrupt vectors, reset and NMI
FBC5 RESET                      ; also the IRQ vector
FDB1 NMI                        ; watchdog first: interrupted PC outside ROM, B/D flag set, stack < $30, NMI re-entered
                                ; or resetCounter = $2D -> NmiWatchdogReset
note FDBB ; stack reads after TSX: $0104,X = pushed P (B/D bits), $0106,X = high byte of the interrupted PC
FFFA NmiVector
FFFC ResetVector                ; JMP (ResetVector) restarts the game
FFFE IrqVector
note FBE7 ; warm reset: $0105-$0114 still holds "HARUHISA UDAGAWA" -> count resets in resetCounter ($0115)
FD3C ColdBootInit               ; first power-on: scoreArea = blank, hiScore = 5000, then ResetBothScores
note FC50 ; game data is stored in CHR ROM: copy PPU $1480-$17FF to RAM $0300-$067F
note FC82 ; copy PPU $098E-$0A3F to RAM $014E-$01FF: song pointer table + songs 1-3
FDD4 NmiWatchdogReset           ; A+B on controller 2: warm reset (keeps the signature), else cold reset
FDDF ResetKeepSignature         ; write the signature back to $0105 and restart through the RESET vector.
                                ; End of both TCRF music player tricks; REVA stores 0 in musicPlayerFlag here
FDF2 ResetCold                  ; destroy the signature and restart through the RESET vector
note FE2D ; timed delay loops: the scroll split is done by cycle counting, there is no sprite-0 hit
FE7C NmiFrameEnd              ; end of NMI: frameCounter, HUD score queue, random table mix, restore registers

; ---- hidden music player (TCRF): reset 44 times, hold A+B on controller 2 and reset,
;      or reset 10 times and shout 4 times into the microphone. Songs are stored in CHR ROM.

note F289 ; uses zp $00 (VRAM address low, increments), $01 (note byte), $02 (VRAM address high), $03 (init done), $04 (tempo mask)
note F321 ; song finished (address low wrapped): clear $0100-$01FF and restart the game through the RESET vector
F32C MusicSq2Period             ; 16 note periods, big-endian (hi, lo); index = high nibble * 2
table F32C-F34B 2 SQ2 period
dbyt F32C-F34B
F34C MusicSq1Period             ; 16 note periods, big-endian (hi, lo); index = low nibble * 2
table F34C-F36B 2 SQ1 period
dbyt F34C-F36B
