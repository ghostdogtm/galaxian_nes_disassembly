# Galaxian — disassembly

A disassembly of **Galaxian** (Famicom, J REVA, NROM: 8 KB PRG at `$E000` + 8 KB CHR) for ca65/ld65. It assembles
byte for byte into the original `Galaxian (J) (REVA) [!].nes` (8 KB PRG + 8 KB CHR). The linker puts 8 KB of `$FF`
padding in front of the PRG (CPU `$C000–$DFFF`) so that emulators accept the ROM; `tools/compare.py` drops the
padding before comparing. The label formats, directives and what is known about the game are described in
`README.md` (Ukrainian, the main one) and `README.en.md` (English).

## Build and check

```
assemble.bat / make          -> galaxian.nes
compare.bat  / make check    -> IDENTICAL
make test                    # check + lint_labels + reloc_test + selftest
```

Without `make`: `python tools/disasm.py --build` (generates and compares), `python tools/lint_labels.py`,
`python tools/reloc_test.py`, `python tools/selftest.py`. The project path contains `!`, so run the `.bat` files from
PowerShell as `& .\assemble.bat`.

## Rules

- Edit the markup (names, code/data/table/text/words, modules) in `tools/labels/rom.txt` and `ram.txt`, operand and
  data constants in `const.txt`, then run `python tools/disasm.py --build`. **`disasm.py` overwrites `src/`** — after
  hand edits of `src/**/*.asm` run it only with `--out DIR`.
- After every change: the build must stay `IDENTICAL`, `lint_labels.py` must report 0 problems, `reloc_test.py` 0
  pointers that did not move, `selftest.py` OK.
- No magic numbers in the code: immediate operands and table data are named with constants from `const.txt`
  (`use`, `data`, `@var`). Only idioms stay numeric (`#0`/`#1`, `EOR #$FF`, `#$FF` as −1). Express sizes through base
  constants. Groups of states are an `enum`, arrays of structures in RAM are a `struct`/`array`.
- PRG is split into the modules `src/prg/*.asm` by `module` lines in `rom.txt`; `src/main.asm` includes them in order.
- The CDL was recorded in Mesen2 (`CDLv2`, 9-byte header). The hidden Music Player (`$F289`) is missing from it — its
  code was found by tracing (flag `T` in the comments of `src/prg/*.asm`).
- Part of the game data lives in CHR ROM (copied to RAM `$0300–$067F` and `$014E–$01FF` at RESET); the Music Player
  songs are there too. `src/chr.asm` with this data is generated by `tools/chrdata.py` (called from `disasm.py`).
- Debugging: `mesen\` (Mesen 2). Run **only one instance at a time and without the GUI** (`--testrunner` + Lua) through
  `tools/mesen/run_profile.py` (it works on a copy of Mesen). For naming use `tools/xref.py [--logs DIR] --unnamed`.
- `(?)` in the label files marks an assumption made from the code; check it before relying on it and remove the mark
  once it is confirmed.
- Language: documentation, code comments and label files are in English. `README.md` is the Ukrainian main README and
  `README.en.md` its English version; keep them in sync.
